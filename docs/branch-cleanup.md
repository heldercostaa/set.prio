# Merged branch cleanup

Verified in GitHub on November 11, 2026.

**Automatically delete head branches** is enabled in the repository's General settings. GitHub removes a pull request's source branch after it is merged, subject to the branch's protection rules.

This is a repository setting, separate from the application and its build. The [repository settings](https://github.com/heldercostaa/set.prio/settings) are the source of truth. Pull requests remain open until a merge is explicitly requested.
