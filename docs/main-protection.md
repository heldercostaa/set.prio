# Main branch protection

Verified in GitHub on November 11, 2026.

The repository's default branch is `main`. The active **Protect main** ruleset targets the default branch and enables:

- Restrict deletions.
- Block force pushes.

The bypass list is empty. These settings are enforced by GitHub; this document records their configuration.

Repository administrators can inspect the [saved ruleset](https://github.com/heldercostaa/set.prio/settings/rules/27079247). Changes to the application continue through pull requests.
